# Changelog

## 2.1.0

### Added

- Added a native JetBrains `.icls` color scheme for PyCharm and other IntelliJ Platform IDEs.
- Added Python-specific highlighting, console colors, diagnostics, search states, Git statuses, and common web-language colors to the JetBrains scheme.
- Documented Cursor support, direct VSIX installation, and VS Code profile import.
- Added Cursor metadata to the extension manifest.
- Updated the landing page with dedicated VS Code, Cursor, and PyCharm installation options.
- Added a direct PyCharm `.icls` download and the public Open VSX listing for Cursor.

### Improved

- Matched the Marketplace and social header image background to the Nicely Neon editor background.

## 2.0.3

### Improved

- Added the Nicely Neon mascot to the Marketplace header image and published README previews.

## 2.0.2

### Improved

- Replaced README previews with full-resolution, unredrawn VS Code captures for crisp syntax rendering.
- Added CSS and full-workspace examples, including a mascot workspace preview.

## 2.0.1

### Improved

- Refined the theme's visible text selection highlight for clearer contrast.
- Added an updated extension icon and refreshed README previews, language examples, and project links.

## 2.0.0

### Improved

- Expanded the workbench palette to 170+ editor, panel, menu, notification, terminal, Git, diff, and minimap colors.
- Added semantic token highlighting for modern language servers.
- Tuned comments, selections, line highlights, indent guides, tabs, and focus states for better hierarchy.
- Added bracket pair colors and guide colors based on the core Nicely Neon palette.
- Added local validation and GitHub Actions checks.
- Added a responsive landing page for the theme.

## 1.0.0

- Initial public release of Nicely Neon.
