# Changelog

## 2.0.0

### Improved

- Expanded the workbench palette to 170+ editor, panel, menu, notification, terminal, Git, diff, and minimap colors.
- Added semantic token highlighting for modern language servers.
- Tuned comments, selections, line highlights, indent guides, tabs, and focus states for better hierarchy.
- Added bracket pair colors and guide colors based on the core Nicely Neon palette.
- Added local validation and GitHub Actions checks.
- Added a responsive landing page for the theme.
